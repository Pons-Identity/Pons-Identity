# Pons Identity

Self-hosted identity provider for SAML 2.0, OpenID Connect, OAuth 2.0 and CAS.

## Features

- Single sign-on for SAML, OIDC, OAuth 2.0 and CAS apps
- Sign-in policies and multi-factor authentication

## Install

Requires Node.js 22.13+.

```sh
npm install
npm run build:web
npm start
```

Open `/setup` and follow the wizard. The one-time setup token is printed in the console.
